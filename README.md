# 🛡️ AliShield (알리익스프레스 렉/프리징 완화 & CPU 보호기)

알리익스프레스(AliExpress) 접속 시 발생하는 **비정상적인 CPU 과점유, 기기 핑거프린팅 연산, 무한 텔레메트리 트래픽**을 원천 차단하여 부드럽고 쾌적한 쇼핑 환경을 제공하는 Chromium 브라우저 확장 프로그램입니다.

---

## ✨ 핵심 기능

1. **악성 트래킹 / 텔레메트리 비콘 차단**
   - 마우스 이동 및 스크롤 시마다 발사되는 `mmstat.com`, `retcode.alicdn.com`, `atanx` 등의 통계 비콘을 네트워크 레벨에서 차단
2. **CPU 혹사 연산 무력화 (0ms 응답)**
   - 백그라운드 WebAssembly(Wasm) 암호화 연산 및 WebGL 3D 핑거프린팅을 원천 차단
   - Canvas 2D 기기 식별 데이터 채취 가로채기
3. **무한 고빈도 타이머 감속 (CPU 휴식 보장)**
   - 0.05초 미만으로 무한 반복 실행되는 내부 감시 타이머 루프를 250ms로 강제 감속
4. **렌더링 극강 최적화 (Deep Freeze)**
   - 화면 밖 상품 카드를 GPU/CPU 렌더링 파이프라인에서 완전히 잠재워 부드러운 스크롤 보장
   - CPU를 태우는 복잡한 그림자(`box-shadow`) 및 애니메이션 완화
   - 상품 비디오 자동 재생 차단
5. **쇼핑 및 결제 기능 100% 정상 작동**
   - 상품 검색, 옵션 선택, 장바구니, 결제 등 모든 정상 쇼핑 기능은 전혀 건드리지 않습니다.

---

## 🚀 설치 방법

> **지원 브라우저**: Chrome, Microsoft Edge, Naver Whale 등 모든 크로미움 기반 브라우저

### Chrome (크롬)
1. 주소창에 `chrome://extensions` 입력 후 엔터
2. 우측 상단 **[개발자 모드]** 활성화 (ON)
3. 좌측 상단 **[압축해제된 확장 프로그램 로드]** 클릭
4. 이 프로젝트 폴더를 선택하면 끝!

### Microsoft Edge (엣지)
1. 주소창에 `edge://extensions` 입력 후 엔터
2. 좌측 메뉴 하단 **[개발자 모드]** 스위치 켜기 (ON)
3. 상단에 나타난 **[압축을 푼 확장 로드]** 클릭
4. 이 프로젝트 폴더를 선택하면 끝!

### Naver Whale (웨일)
1. 주소창에 `whale://extensions` 입력 후 엔터
2. 우측 상단 **[개발자 모드]** 활성화 (ON)
3. **[압축해제된 확장 프로그램 로드]** 클릭 후 폴더 선택!
